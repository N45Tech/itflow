# Ticket workflow consolidation

Operate. Preserve the incumbent desktop PSA and Field Mode visual system. Follow-ups belong in the ticket filters, with plan details disclosed on the ticket. Canned responses belong in Administration for management and in the unsent ticket composer for use. Mobile devices automatically use Field Mode; desktop users have no mode switch.

Keep existing ticket list density, native form controls, visibility choices, client scope, and review-before-send behavior. Field Mode retains spruce, paper, teal, readable prose, and touch controls. Canned response insertion adds text without sending or discarding an existing message. Administration and customer portal routes remain distinct.

The prior standalone follow-up queue and knowledge authoring/review UI are superseded by the user's explicit workflow correction. Existing records and retention protections remain. This is a local extension and consolidation, with no new visual world, seed, comp, raster assets, or global token changes. See `docs/n45/service-assistance.md` for behavior and release boundaries.

Verification captures for this revision belong under `.impeccable/review/ticket-workflow/`; these use disposable fixtures. Stage on `next` without deployment.
