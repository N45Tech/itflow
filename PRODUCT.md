# Product

## Register

product

## Platform

web

## Users

N45 technicians use ITFlow to document client environments, manage support
tickets, and handle quotes, invoices, and payments. N45 clients use the portal
and transactional emails to follow support work, review billing, and complete
time-sensitive account actions.

## Product Purpose

ITFlow is N45's operational system of record for service delivery. It should
make routine work easy to understand, keep client communication consistent,
and give both technicians and clients a clear next action without exposing
unnecessary technical detail.

## Brand Personality

Capable, grounded, and quietly modern. Communication should sound like a
trusted local operator: calm, direct, useful, and specific.

## Anti-references

Avoid generic SaaS styling, decorative gradients, fear-based security copy,
oversized claims, unexplained technical jargon, and dense system-generated
messages that make the recipient hunt for the requested action.

## Design Principles

1. Lead with the outcome and the next useful action.
2. Preserve operational context without overwhelming the recipient.
3. Use N45's identity consistently across the portal and every message.
4. Treat accessibility and resilient fallbacks as production requirements.
5. Keep customizations isolated so upstream ITFlow updates remain manageable.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast for customer-facing interfaces and messages.
Emails must include meaningful link text, useful alternative text, a complete
plain-text part, mobile-safe layouts, and information that does not depend on
color alone.
